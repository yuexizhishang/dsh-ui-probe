# DSH 图形界面插件测试工具（dsh-ui-probe）

**在真实运行的 DeepSeek Harness 界面里自动测试插件页面。**

UI 探针让 DeepSeek Harness 在做图形化界面插件时，能够自己把界面切换到目标插件页面、读取信息、验收调试插件功能。

具体功能有：读取插件界面的布局、文字与样式（尺寸、颜色、间距），点击页面按钮，往输入框填内容，等待异步结果出现，以及抓取控制台报错。

在调用完之后，插件会自动回到原对话界面，让对话继续工作。

---

## 安装

**方式一：从 DeepSeek Harness 桌面端安装（推荐）**

在 DeepSeek Harness 的「插件 → 添加插件」里粘贴下面这行，点安装：

```text
github:yuexizhishang/dsh-ui-probe
```

等价的完整地址是 `https://github.com/yuexizhishang/dsh-ui-probe`。

**方式二：从 npm 安装**

在 DeepSeek Harness 的「插件 → 添加插件」里粘贴下面这行，点安装：

```text
@yuexizhishang/dsh-ui-probe
```

装的是预构建好的版本，不需要编译。

**方式三：下载后从本地安装**

```powershell
git clone https://github.com/yuexizhishang/dsh-ui-probe.git
```

然后把克隆下来的目录路径告诉对话，让 AI 帮你安装即可。

安装完成后如果提示需要重启，重启一次 DeepSeek Harness 即可。

**装完不用配置任何东西。** 插件自带一套发现机制：对话里会多出 `ui_probe` 和 `ui_page` 两个工具，技能列表里会出现「dsh-ui-probe」的指南，模型读到描述就会知道什么时候该用它。卸载插件时这些一起消失，不往系统里留文件。

## 用起来是什么样

直接对对话说一句就行，比如：

> 验收一下便签插件，看一下界面和插件功能有没有问题。

对话会按三步走：

| 步骤 | 做什么 |
|---|---|
| **打开** | 切到目标插件页面，并记住你原来的对话，供之后返回 |
| **操作** | 一步一个动作，可以连续做很多步：点击、按文字找元素、读计算样式、填表单、按键、等结果出现、页面快照（可见标题与按钮清单） |
| **收尾** | 返回全程时间线 + 页面快照 + 控制台报错，然后自动回到你的对话 |

它能做的动作：

- **读真实界面**：元素的实际尺寸、位置，以及字号、颜色、内外边距、圆角、不透明度等计算样式
- **点按钮**：按可见文字或 CSS 选择器定位；文字出现在聊天记录里时，可以限定只在某个容器内找
- **填表单**：普通输入框、文本域、富文本编辑器都支持，写完会回读校验，写不进去会明确报失败而不是假装成功
- **按键盘**：回车、Esc、退格等
- **等异步**：轮询等待某个元素出现，适合"加载中→出列表""点完弹提示"这类延迟生效的效果
- **抓报错**：把控制台里的错误一并带出来，界面崩了不会没声音

如果你只想快速看一眼某个面板长什么样，还可以让它打开、读一次、立刻回来，不用走完整流程。

**不用担心它赖着不走**：验收结束会主动返回；中间 30 秒没有新动作会自动收尾；页面意外刷新后也会照着记录的起点回到原对话。

## 插件设置页

「设置」的侧栏里会多出一栏「UI 探针」，提供三件事：

| 功能 | 说明 |
|---|---|
| 检查更新 | 打开即自动比对 GitHub 上的版本，显示当前版本、最新版本和状态；网络不通或仓库不可达时如实报错，不会假装"已是最新" |
| 更新并安装 | 有新版才可点；已经是最新则跳过，不会重复安装 |
| 卸载插件 | 二次确认后卸载；**只移除这个插件本身，不删除任何你自己的文件或仓库** |

插件本身**不会去打开设置面板**。

## 安全边界

**设置、账号、余额、充值和账号菜单，对自动化完全封闭。**

- 账号菜单按钮不会被点开，菜单内的任何操作一律拒绝；
- 设置面板内的点击、输入、按键同样一律拒绝；
- 万一某个操作意外打开了设置面板或账号菜单，会立刻关掉并报告"已拒绝"；
- 唯一例外是插件自己的设置页（版本 / 更新 / 卸载那一栏）。

## 已知限制

| 做不到 | 原因 |
|---|---|
| 从一个面板自动点回另一个面板 | 页面没有可靠的"当前面板"标记，需要显式再点一次 |
| Canvas / 自绘编辑器里的输入 | 只支持标准输入框、文本域和普通富文本 |
| 同时跑多个验收任务 | 一次只能有一个任务，后到的会排队 |

**不需要截图也能验收**：插件拿到的是尺寸、样式、文字和控制台报错这些可核对的值，比看截图更准。要一张图给别人看观感，用系统自带截图即可（Windows `Win+Shift+S`、macOS `Shift+Cmd+4`）。
